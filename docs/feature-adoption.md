# 外部特徴量 採用判断表

本ドキュメントは、外部特徴量を本番モデル、参考表示、保留のどれで扱うかを管理する。

採用判断では、精度指標だけでなく、ONNXサイズ、辞書サイズ、フロントエンド推論時の再現性、データ更新のしやすさ、表示価値を合わせて確認する。

## 判断区分

| 区分 | 意味 |
| --- | --- |
| モデル採用済み | 本番モデルの特徴量として利用している |
| モデル採用候補 | 次回比較で本番採用を優先検証する |
| 参考表示のみ | モデルには入れず、画面表示または地図レイヤーで扱う |
| 検証保留 | データ取得、比較、出典確認が未完了 |
| 不採用 | 現時点の比較で効果や運用価値が低い |

## 本番モデル候補の優先順位

次回のモデル候補は、まず以下を優先する。

1. 地価
2. 用途地域
3. 人口統計

教育施設と犯罪統計は、初期段階では参考表示を優先し、モデル採用は比較結果と表示リスクを確認してから判断する。

## 採用時の確認事項

モデル採用候補を `configs/*.yaml` へ追加する前に、以下を確認する。

* MAE/RMSE/MAPEが複数条件で安定して改善している
* ONNXサイズとメタデータサイズが許容範囲に収まる
* ブラウザ推論時に同じ特徴量を再現できる
* 欠損時のdefault値と欠損フラグの扱いが明確である
* Feature Importanceで欠損フラグやデータ提供範囲だけが上位になっていない
* 参考表示する場合は、出典、年度、集計単位、モデル採用状況を表示できる
